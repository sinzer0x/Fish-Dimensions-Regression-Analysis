# Model Card: FishGrow Weight Predictor (`E4_Ridge_With_Volume`)

## 1. Общая информация
* **Название модели:** `FishGrow_Ridge_Volume_v0.1`
* **Артефакт модели:** `models/best_model.joblib` (зарегистрирован в MLflow, эксперимент `FishGrow_Regression`, запуск `E4_Ridge_With_Volume`).
* **Тип задачи:** Табличная регрессия (прогнозирование массы рыбы `Weight` в граммах).
* **Архитектура конвейера:**
  1. `VolumeAdder`: генерация производного признака $V_{proxy} = Length3 \times Height \times Width$.
  2. `ColumnTransformer`:
     * Числовые признаки (`Length1`, `Length2`, `Length3`, `Height`, `Width`, `V_proxy`): `SimpleImputer(strategy="median")` $\rightarrow$ `StandardScaler()`.
     * Категориальный признак (`Species`): `SimpleImputer(strategy="most_frequent")` $\rightarrow$ `OneHotEncoder(handle_unknown="ignore")`.
  3. Регрессор: `Ridge` (L2-регуляризация с подбором $\alpha$ по 5-фолдовой кросс-валидации).

## 2. Данные обучения и валидации
* **Источник:** Набор данных измерений рыб (`data/processed/fish_checked.csv`, 158 валидных записей после исключения 1 дефектной строки с `Weight = 0`).
* **Разбиение:** Стратифицированный сплит по `Species` (`train`: 126 строк, `test`: 32 строки, `random_state=42`).
* **Входные признаки (6 обязательных столбцов):**
  * `Species` (строка): биологический вид (`Bream`, `Roach`, `Whitefish`, `Parkki`, `Perch`, `Pike`, `Smelt`).
  * `Length1`, `Length2`, `Length3` (float, см): вертикальная, диагональная и полная длина тела.
  * `Height`, `Width` (float, см): максимальная высота и толщина тела.

## 3. Метрики качества (отложенная тестовая выборка, $N=32$)
* **$R^2$ (коэффициент детерминации):** `0.9707` (на кросс-валидации: `0.9602`)
* **$MAE$ (средняя абсолютная ошибка):** `48.37 г`
* **$MSE$ (средняя квадратичная ошибка):** `5638.63 г²`
* **95% предиктивный интервал (бутстрэп, $B=500$):** средняя ширина `246.29 г`, фактическое покрытие на тесте `96.9%`.

## 4. Область применения и ограничения прототипа
* **Рекомендуемое применение:** Автоматизированная оценка массы промысловых видов рыб по оптическим или ручным замерам габаритов в диапазоне масс от $10\text{ г}$ до $1200\text{ г}$.
* **Ограничения и риски:**
  1. **Гетероскедастичность и крупные особи:** Ошибка растёт пропорционально массе рыбы ($MAE = 23.60\text{ г}$ для рыб $<250\text{ г}$ против $99.13\text{ г}$ для рыб $>700\text{ г}$). На особях тяжелее $1300\text{ г}$ модель склонна занижать прогноз.
  2. **Единый коэффициент формы:** Модель использует общий линейный вес для $V_{proxy}$ без учёта взаимодействия с видом рыбы, что снижает точность на вытянутых видах (`Pike`, $MAE = 92.15\text{ г}$).
  3. **Новые виды рыб:** При передаче неизвестного вида (`Species`) энкодер закодирует его нулевым вектором; прогноз останется конечным, но сместится к усреднённой плотности всех видов.
  4. **Малый размер обучающей выборки:** Модель обучена на 126 объектах и требует дообучения при расширении географии или сезонов вылова.
